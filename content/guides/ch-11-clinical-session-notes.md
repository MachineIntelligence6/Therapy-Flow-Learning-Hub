# Chapter 11 - Clinical Session Notes

**Slug:** `ch-11-clinical-session-notes`  
**Audience:** Admin and Therapist  
**Order:** 11000

Record the clinical conversation for a session, use the transcript to fill the session note, and finalize the note when work is complete.

**Primary paths**

| Role | How to open the session |
|------|-------------------------|
| Admin | **Clients** → open client → **Sessions**, or **Scheduling** |
| Therapist | **Clients** → open client → **Sessions**, or **Scheduling** |

You need an existing session with a client. Book sessions first (Chapter 5 Admin, or Chapter 8 Therapist).

---

## 11.1 Record a session for notes

Use this when you want AI-supported notes from a live session recording.

1. Open the client and go to the **Sessions** tab, or find the session on **Scheduling**
2. On the session card, open the **⋮** actions menu
3. Choose **Record Session**
4. Allow microphone access if the browser asks
5. In the record modal, confirm language if needed (for example **English (US)** or **Auto detect**)
6. Start recording when the session conversation begins
7. Speak a clear therapist and client turn-taking conversation (questions from the therapist, answers from the client)
8. When the session talk is done, stop and save so the transcript can finalize
9. Wait until processing finishes
10. Confirm the session shows **Show Transcript** in the ⋮ menu (recording is saved)

You cannot record again on a session that already has a transcript, or when session notes are already finalized as blocked by the product.

---

## 11.2 Review the transcript and identify speakers

1. On the same session, open **⋮** → **Show Transcript**
2. Review the transcript text and timestamps
3. When the transcript is ready, click **Identify Speakers**
4. Wait for labeling to complete
5. Confirm turns show as **Therapist:** and **Client:** (use the toggle to compare with the original if shown)
6. Close the transcript when you are ready to build the note

Identify Speakers needs a finalized transcript. If the button is not available yet, wait until the transcript is ready and try again.

---

## 11.3 Add the session note and Smart Fill

1. On the session card, open **Add Note** (after a note exists the label is usually **View Note**)
2. The modal title is **Add Session Note** (or **Session Note Edit** when updating)
3. Open **Clinical Actions**
4. Choose **Smart Fill from transcript**
5. Wait for smart fill to finish
6. Review clinical fields that were filled (for example session focus, symptoms, goals, interventions, progress, ratings, mood, risk items when the speech covered them)
7. Correct or complete any empty fields by hand
8. Optionally run **Generate Final Note** from **Clinical Actions** after you select or create a template and at least one clinical field has content
9. Optionally use **Create Template** if you need a new note template for final generation

Smart Fill pulls from the session transcript. Better recordings and complete transcripts produce better field fills.

---

## 11.4 Finalize the session note

1. Stay in the session note modal
2. Review clinical fields and any generated final note text
3. Use **Draft** while work is still in progress
4. When ready to lock the chart entry, turn on **Finalized** (draft turns off)
5. Click **Save Note**
6. Confirm the session shows note actions such as **Download PDF** or **Reopen Note** when those are available for your role and status

After notes are finalized in a way that blocks recording, you cannot record that session again. Use **Reopen Note** only when the product allows it and your process needs edits.

### Quick checklist

| Step | Action |
|------|--------|
| 1 | Session card → **Record Session** → stop and save |
| 2 | **Show Transcript** → **Identify Speakers** (optional but recommended) |
| 3 | **Add Note** → **Clinical Actions** → **Smart Fill from transcript** |
| 4 | Review fields → set **Finalized** → **Save Note** |

---

Open **Scheduling** or the client **Sessions** tab whenever you return to continue this flow for another appointment.
